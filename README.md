
# E-Commerce SDET Automation Framework

An end-to-end Software Quality Engineering portfolio project demonstrating UI automation, API testing, database validation, performance testing and CI/CD integration.

## Technology Stack

- JavaScript
- Playwright
- Postman
- Newman
- PostgreSQL
- Jenkins
- Docker
- GitHub
- Allure Reports
- k6
- axe-core

## Application Under Test

SauceDemo: https://www.saucedemo.com/

## Project Objectives

1. Develop a reusable Playwright automation framework.
2. Perform functional and regression testing.
3. Automate API test scenarios.
4. Validate backend data using SQL.
5. Integrate automated tests into Jenkins.
6. Generate detailed test execution reports.
7. Demonstrate modern SDET engineering practices.
