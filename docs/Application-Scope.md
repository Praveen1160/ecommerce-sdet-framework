
# E-Commerce Application - Project Scope

## 1. Project Overview

This project demonstrates an end-to-end Software Development Engineer in Test (SDET) framework for testing an e-commerce application.

The project uses SauceDemo as the primary application under test.

## 2. Application Under Test

Application: SauceDemo

URL: https://www.saucedemo.com/

Application Type: E-Commerce Demo Application

## 3. Business Features

- User Authentication
- Product Listing
- Product Sorting
- Shopping Cart
- Checkout
- Order Confirmation

## 4. Testing Scope

### Functional Testing

- Login and logout
- Product listing and sorting
- Add and remove cart items
- Checkout workflow
- Order confirmation

### UI Automation

- Playwright with JavaScript
- Page Object Model
- Reusable fixtures
- Cross-browser testing
- Screenshot and trace capture

### API Testing

- Postman collections
- Newman execution
- Playwright API testing
- Positive and negative API scenarios

### Database Testing

- PostgreSQL
- SQL queries
- Customer and order validation
- Data integrity checks

### Non-Functional Testing

- Accessibility testing
- Performance testing
- Basic security scanning

### CI/CD

- Jenkins pipeline
- Docker-based test execution
- GitHub Actions for pull request checks

## 5. Out of Scope

- Real financial transactions
- Actual payment gateway integration
- Production customer data
- Unauthorized security testing

## 6. Expected Deliverables

- Manual test cases
- Test strategy
- Requirement Traceability Matrix
- Playwright automation framework
- API automation collections
- Database validation scripts
- Automated execution reports
- Jenkins pipeline
- GitHub documentation
